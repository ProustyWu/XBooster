# Contributing

Thanks for considering contributing to XBooster.

## How to Contribute

1. Fork the repo and create a feature branch.
2. Make focused changes with clear commit messages.
3. Run `pnpm lint` and ensure the extension still builds.
4. Open a PR with a clear description of changes and testing notes.

## Guidelines

- Keep privacy and security considerations in mind.
- Avoid logging sensitive data (API keys, user content).
- Prefer small, well-scoped pull requests.

## Reporting Issues

Use the issue templates provided in `.github/ISSUE_TEMPLATE`.
