# Privacy Policy (Draft)

## Data We Store
- API keys and user settings are stored locally in the browser.
- No server-side storage is used by this extension.

## Data We Send
- Requests are sent only to the selected AI provider's official API endpoint.
- X (Twitter) content is sent only to the selected provider for generation.

## Data We Do Not Collect
- We do not collect or store personal data on our servers.
- We do not track user behavior or analytics.

## Security Notes
- API keys are handled by the extension and never logged.
- You can remove all stored data by clearing the extension's storage.
